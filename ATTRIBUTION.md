# Asset Attribution & Licensing

This is a fictional demonstration project. All content is either procedurally generated or hand-authored for the purpose of this concept.

## 3D Assets & SVG Illustrations
- The 3D hero scene (DNA helix, orbs, particles) is generated at runtime using **Three.js** primitives. No external `.glb` or `.gltf` models were downloaded.
- All 2D illustrations (doctors, departments, services, facilities, articles) are hand-authored SVG code located in `src/utils/illustrations.js`. They are original to this project and carry no third-party licensing obligations.
- No icon fonts (FontAwesome, Lucide, etc.) were used. All interface icons are inline SVGs or CSS shapes.

## Fonts
- **Sora** and **Inter** are loaded from Google Fonts under the SIL Open Font License (OFL).
- If you deploy this project to production, ensure Google Fonts compliance by considering self-hosting the `.woff2` files (as recommended by GDPR guidelines).

## Content
- All text, doctor names, testimonials, and statistics are fictional and were written specifically for this concept. They do not describe any real person, hospital, or medical outcome.
