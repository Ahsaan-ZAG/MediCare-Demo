# MediCare Hospital — 3D Glassmorphism Healthcare Demo

> **Fictional demonstration project.** Not affiliated with any real hospital or
> healthcare provider. No appointments are booked, no patient data is collected.

A premium, multi-page static website concept for a fictional multi-specialty
hospital, featuring a real interactive Three.js hero scene, full-site
glassmorphism, and cinematic GSAP motion.

- npm 9+
